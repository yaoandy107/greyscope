# Benchmarks

The release results are in the main [README](../README.md) and model card. This directory pins the
data and model versions used for them:

- [`results/v2-summary.json`](results/v2-summary.json) contains the published metrics.
- [`manifests/`](manifests/) pins each dataset sample.
- [`configs/release_eval.json`](../configs/release_eval.json) pins every model revision.

Raw predictions are generated locally and are not committed.
